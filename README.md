## 📌 项目概述

本项目基于 **全球 Top YouTuber 数据集**（涵盖 2023 年订阅数最高的 YouTube 频道），通过多工具融合分析（Tableau + Python + R），探索**内容类别、国家特征、创作者表现与收入之间的关联**。项目旨在回答以下核心问题：

- 哪些类型的频道最受欢迎？  
- 地理位置是否影响频道成功？  
- 国家的教育水平、城市化率与创作者表现有何关系？  
- 视频上传频率与收入是否存在转换路径？  

项目综合运用**地理可视化、相关性分析、聚类建模、网络图与桑基图**，揭示全球数字内容生态的结构性规律。

---

## 🔍 数据描述

数据包含 **频道级指标** 与 **国家宏观经济变量** 两大维度：

### 📊 频道指标
- 订阅数（subscribers）、总播放量（video views）
- 上传视频数（uploads）、创建时间（created_year）
- 频道类别（category）、频道类型（individual/brand）
- 月/年收入估算（lowest/highest earnings）

### 🌍 国家级指标
- 人口、城市化率（Urban_population %）
- 高等教育毛入学率（Gross tertiary education enrollment %）
- 失业率、地理坐标（Latitude/Longitude）

## 🔑 关键发现

### 1. **内容类别表现差异显著**
- **娱乐类**（Entertainment）：频道数量、订阅数、上传量均居首位。
- **新闻类**（News）：上传频率极高，但订阅数低，体现“快节奏但低粘性”。
- **音乐类**（Music）：订阅数第二高，全球接受度最广。
- **动物类**（Animals）：订阅数低，但**平均月收入最高**，广告变现能力强。

### 2. **地理与社会经济影响创作者生态**
- **美国、巴西、印度、印尼** 是 Top YouTuber 最集中的国家。
- **高等教育率** 与 **创作者收入** 呈正相关（如韩国、新加坡）。
- **高城市化率国家** 更容易孕育头部频道（数字基础设施更完善）。
- **人口大国 ≠ 频道强国**：印度人口庞大，但 Top 频道集中度低于美国。

### 3. **国家聚类揭示发展梯度**
使用 K-means 将国家分为三类：
- **高教育/高城市化/低失业**（欧美、日韩）
- **高人口/低教育**（新兴市场）
- **中等发展水平**（拉美、东南亚部分国家）

第一类国家在 YouTube 顶级创作者中占据主导地位。

### 4. **上传频率 → 收入存在转化路径**
- 桑基图显示：**高上传量 → 高收入** 的转化比例显著。
- 但收入也受**内容质量与影响力**调节，单纯堆量并非万能。

### 5. **特征重要性：播放量排名最关键**
- 随机森林模型显示：**视频播放量排名**（video views rank）对订阅数的预测能力远超其他变量。

## 💡 实践建议

### 对创作者：
- 优先选择 **娱乐、音乐、教育** 等高订阅或高变现类别。
- **保持高频更新**，同时提升内容质量以增强影响力。
- 根据本国观众偏好（如印度爱娱乐、韩国爱音乐）本地化内容。

### 对政策制定者：
- 提升**高等教育**与**数字基础设施**，有助于培育本土数字创作者经济。

### 对平台/广告主：
- **动物、教育、喜剧类** 频道具有高广告价值，值得重点关注。
